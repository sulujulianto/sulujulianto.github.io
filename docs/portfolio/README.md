## Urutan umum perubahan portfolio

1. Sinkronkan `main` dan buat branch baru.
2. Pilih panduan berdasarkan pekerjaan.
3. Ubah hanya source atau data yang diperlukan.
4. Jalankan pemeriksaan yang tertulis pada panduan.
5. Periksa tampilan melalui server lokal.
6. Tinjau diff dan stage file secara eksplisit.
7. Commit, push, buat Pull Request, dan tunggu CI.
8. Setelah merge, periksa GitHub Pages.
